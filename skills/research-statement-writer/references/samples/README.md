# Sample research statements

This folder is for real research statements from **successful** faculty, postdoc or fellowship applications. The skill reads them to learn how strong statements are actually structured and phrased, so every well-chosen sample makes the skill better.

## How to contribute a sample

1. Only contribute a statement you have the right to share — your own, or one whose author has given permission or has already posted it publicly (many faculty post theirs on their websites; link the source).
2. Name the file `<field>-<institution-type>-<year>.pdf`, e.g. `mech-eng-r1-2024.pdf`, `biology-pui-2023.pdf`, `hci-r1-2019.pdf`. Add a `.md` companion with the same stem if you can share a short note: what position it was for, what the author thinks made it work, and any identifying details you prefer removed.
3. Keep the file as the applicant submitted it (PDF preferred) so formatting, figures and length are visible.
4. Open a pull request. Mention the field and institution type in the PR title.

Anonymized samples are welcome — remove the name and affiliation but keep the content, venues and structure intact.

## What makes a sample useful

- It got an interview or an offer.
- It shows a structure the skill does not yet cover well (humanities book plans, clinical/medical-school statements, non-US funding bodies, teaching-focused positions).
- It includes figures, a self-citation list, or a funding paragraph done well.
